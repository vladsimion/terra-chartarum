## Method

The essay uses `plate`, `state`, `edition` and `impression` as separate terms.
A plate is the engraved matrix. A state is a materially altered condition of that
matrix. An edition is a publisher’s configuration of an atlas and its text. An
impression is one pull from a plate. The same state can appear in several editions;
one edition can contain mixed states. The draft treats uncertainty as data rather
than smoothing it into a single nominal date.
